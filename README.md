Feedback Tracker

A simple feedback tracker built with React, allowing users to submit their feedback (Good, Neutral, or Bad) and see statistics about the feedback received.

📄 Project Overview

This project allows users to give feedback on various aspects (Good, Neutral, Bad), and then tracks and displays the count of each type of feedback, along with a message summarizing the overall feedback sentiment. It was built using React, Vite, and hosted on GitHub Pages.

⚙️ Features

- Give Feedback: Users can select from three feedback options: Good, Neutral, and Bad.
- Statistics: Displays the number of Good, Neutral, and Bad feedback received, as well as the total feedback count.
- Sentiment Analysis: Based on the feedback received, the app provides a message indicating whether the feedback is "Mostly Good," "Mostly Neutral," "Mostly Bad," or "Mixed Feedback."

🚀 How to Run the Project Locally

1. Clone the repository:

    ```bash
    git clone https://github.com/AyangealumunTerna/Feedback-tracker.git
    cd Feedback-tracker
    ```

2. Install dependencies:

    ```bash
    npm install
    ```

3. Run the development server:

    ```bash
    npm run dev
    ```
